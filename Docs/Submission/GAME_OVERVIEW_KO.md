# 이 멋진 적에게 축복을

## 한 줄 소개

직접 공격할 수 없는 축복술사가 적을 실제로 강화하고, 강해진 적의 공격을 다른 적과 환경으로 유도해 살아남는 2D 탑다운 액션 퍼즐.

> 강한 적을 쓰러뜨리는 게임이 아니라, 적을 강하게 만든 책임을 지는 게임.

| 항목 | 내용 |
|---|---|
| 장르 | 2D 탑다운 액션 퍼즐 |
| 플랫폼 | PC 데스크톱 웹 브라우저 (Unity WebGL) |
| 플레이 인원 | 싱글 플레이 |
| 목표 플레이 시간 | 10~15분 |
| 기준 해상도 | 1920×1080 (최소 1280×720), 16:9 고정 |
| 엔진 | Unity 6000.0.72f1, URP 2D |

## 게임 방법

### 목표

플레이어는 적에게 **피해를 줄 수 없다.** 공격 버튼이 없다. 할 수 있는 일은 적을 **더 강하게 만드는 것**뿐이다.

축복을 받은 적은 실제로 더 빠르고, 더 크고, 더 넓게 공격한다. 강해진 그 공격이 **다른 적에게 맞도록** 위치를 잡고, 마지막 순간에 비켜서면 적이 서로를 처치한다. 적이 쓰러지면 영혼 조각이 떨어진다.

한 방을 통과하는 조건은 두 가지다.

1. 영혼 조각 **3개**를 모은다. 영혼은 적이 서로를 처치했을 때만 나온다.
2. 열린 출구로 들어간다.

방은 총 **3개**다. 방을 지날수록 조건이 하나씩 늘어난다.

| 방 | 새로 배우는 것 |
|---|---|
| ROOM 01 | 축복 두 종류(과속·거대화)와 유도의 기본 |
| ROOM 02 | 메아리 축복. 고정된 공격을 잠시 뒤 한 번 그대로 반복시킨다 |
| ROOM 03 | 시야를 끊는 고정 기둥. 경로 선택과 메아리를 함께 쓴다 |

### 등장 인물

| 이름 | 역할 | 공격 습관 |
|---|---|---|
| 리벨라 (Rivella), 22 | 플레이어. 냉소적인 전직 성녀 | 직접 때리지 않는다. 서로를 망칠 때까지 과잉 축복한다 |
| 베라 (Vera), 24 | 붉은 번개 돌진 기사 | 직선으로만 가속하고 고정 후에는 조향하지 않는다 |
| 루메 (Lume), 23 | 월식 궁수 | 원거리에서 침착하며, 이미 고정한 레인으로 계속 쏜다 |
| 모코 (Moko) | 저주받은 인형 군체 | 가장 가까운 상대를 모방하고 짧은 예고가 끝나면 즉시 휘두른다 |

각 인물은 첫 조우·축복 선택·승리·패배 네 시점에만 화면에 카드로 등장한다. 전투 판단은 항상 픽셀 스프라이트와 공격 예고가 기준이다.

### 조작

| 입력 | 기능 |
|---|---|
| `W` `A` `S` `D` 또는 방향키 | 이동 |
| `Space` | 대시 |
| `1` / `2` / `3` | 과속 / 거대화 / 메아리 축복 선택 (메아리는 ROOM 02부터) |
| 마우스 이동 | 적 확인 및 대상 지정 |
| 좌클릭 | 선택한 축복을 지목한 적에게 적용 |
| 우클릭 | 선택 취소 |
| `R` | 현재 방 재시작 |
| `Esc` | 선택 취소 또는 일시정지 |

### 공격 읽는 법

모든 적의 공격은 `예고 → 방향·범위 고정 → 실행 → 회복` 순서를 지킨다. **고정된 뒤에는 플레이어를 다시 추적하지 않는다.** 이 규칙이 이 게임의 유도가 성립하는 이유다.

예고는 색만으로 구분하지 않고 형태로 구분한다.

| 공격 | 예고 형태 |
|---|---|
| 돌진 | 두꺼운 직선 + 화살표 |
| 관통 사격 | 가는 점선 + 투사체 아이콘 |
| 충격파 | 원형 또는 부채꼴 면 |
| 메아리 | 반투명 2차 예고 + 이중 테두리 |

### 종료 조건

| 결과 | 조건 | 이후 |
|---|---|---|
| 방 통과 | 영혼 3개 수집 후 출구 진입 | 다음 방으로 이동. ROOM 03을 통과하면 결과 화면 |
| 완주 | ROOM 03 통과 | `RUN COMPLETE` 결과 화면 → 클릭하면 타이틀로 |
| 패배 | 체력 6 소진 | 화면에 안내가 표시된다. `R`로 그 방을 처음부터 다시 시작 |

패배해도 게임 오버 화면에서 막히지 않는다. 같은 방을 원하는 만큼 다시 시도할 수 있다.

## 실행 방법

별도 설치, 계정, 유료 라이선스가 필요하지 않다. 브라우저에서 링크를 열면 바로 실행된다.

1. 아래 플레이 링크를 최신 데스크톱 Chrome 또는 Edge에서 연다.
2. 로딩이 끝나면 타이틀 화면이 나온다. **아무 곳이나 클릭**하면 첫 방으로 들어간다.
3. 방에 들어가면 `CLICK TO BEGIN` 안내가 나온다. 한 번 더 클릭하면 게임이 시작된다.
   브라우저는 사용자의 실제 입력이 있기 전에는 소리와 타이머를 시작할 수 없기 때문에, 방마다 이 확인을 한 번 받는다.
4. 화면 우측 하단의 전체 화면 버튼으로 크게 볼 수 있다.

권장 환경: 데스크톱 Chrome/Edge 최신 버전, 1280×720 이상, WebGL2 지원. 모바일 브라우저는 대상이 아니다.

### 플레이 링크

```
<제출 전 채워야 함: https://<사용자>.github.io/KONOSUBA/>
```

이 링크는 저장소의 `gh-pages` 브랜치를 GitHub Pages로 서비스한 주소다. 저장소를 공개로 전환하고 Pages 설정에서 브랜치 `gh-pages`의 루트를 선택하면 활성화된다. 배포된 웹 빌드는 `Tools/publish_gh_pages.py`가 `Builds/Overbless_Web`의 산출물을 그 브랜치에 올린 것이다.

### 플레이 영상 링크

```
<제출 전 채워야 함: YouTube 링크>
```

### 소스 코드

```
https://github.com/digdagdac/KONOSUBA
```

게임 전체 소스와 커밋 기록이 같은 저장소에 있다. 배포된 웹 빌드는 같은 저장소의 `gh-pages` 브랜치에 있고, 그 커밋 메시지에 빌드를 만든 소스 커밋이 적혀 있어 심사자가 보는 화면과 소스의 대응을 확인할 수 있다.

| 항목 | 상태 |
|---|---|
| 방 | 3개 (ROOM 01 / 02 / 03) + 타이틀 + 결과 화면 |
